# @axitnow 계정 설정

올리기 전에 한 번만 해 두면 되는 것들. 복사해 쓰라고 적어 둔다.

## 이름 (검색에 걸리는 칸, 30자)

```
AX-it NOW · 매일 AI 뉴스
```

`@axitnow`는 아이디라 검색이 잘 안 걸린다. 사람들이 치는 말은 "AI 뉴스"
쪽이므로 **이름 칸에 그 말을 넣는다.** 인스타그램 검색은 아이디와 이름을
같이 본다.

## 소개 (150자)

```
AI가 디자인·마케팅·영화·의학·정책을 바꾸는 현장
매일 아침 열 개 분야, 카드 한 장씩 정리합니다
원문 교차 확인 후 작성 · 전문은 아래 링크에서 ↓
```

83자. "원문 교차 확인 후 작성"을 빼지 말 것 — 요약 계정과 구별되는 거의
유일한 줄이고, 메타의 비오리지널 콘텐츠 정책에서도 이쪽이 안전하다.

## 링크

1순위 `https://axitnow.com`. 인스타그램은 링크를 여러 개 걸 수 있으니
회차 주제에 맞는 섹션을 두 번째로 걸면 그날 유입이 섞이지 않는다.

## 캡션에 반드시 들어갈 것

매체의 취재를 옮기는 것이므로 **캡션 첫 줄이나 끝에 출처 매체와 날짜**를
적는다. 카드 푸터에도 적지만 캡션에 없으면 공유될 때 떨어져 나간다.

## 계정 종류

**크리에이터**로 전환한다(설정 → 계정 유형 및 도구 → 프로페셔널 계정 전환).
비즈니스 계정은 음원 라이브러리가 상업용으로 제한되는데, 이 콘텐츠는
영상 카드가 많아 음원 선택지가 좁아지면 손해다. 카테고리는 `뉴스 및 미디어`.

둘 다 프로페셔널 계정이라 나중에 API 자동 게시를 붙일 때 막히지 않는다.

## 먼저 켜 둘 것

- **2단계 인증.** 선점한 아이디라 뺏기면 되찾기가 가장 어렵다.
- **페이스북 페이지 연결.** 수익화·광고·API가 전부 여기에 걸려 있다.
- 공개 계정 유지(비공개면 아무것도 퍼지지 않는다).

`outro` PNG 한 장이다. 순서대로 `card1`…`card6`을 올린다.
